# CAD elettrico — installer

Questo repository contiene solo gli installer Windows di **CAD elettrico** (sezione Releases).
L'app installata li usa per aggiornarsi da sola. Il codice sorgente è privato.

Installazione: scaricare `CAD-elettrico-Setup-<versione>.exe` dall'ultima release e avviarlo.
L'installer non è firmato: Windows SmartScreen chiede conferma (Ulteriori informazioni > Esegui comunque).
